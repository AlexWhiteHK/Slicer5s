# What AI Can Do — a 60-second history, in pixels

`what-ai-can-do.mp4` — 1920×1080, 30 fps, 60 s, H.264 + AAC stereo.

A pixel-art promo/explainer: the question *"What can AI do?"* is answered one
milestone at a time, 1943 → 2026. Each milestone unlocks a skill in a game-style
hotbar (15 in total); the picture's colour depth evolves with the era (1-bit paper →
amber and green CRT → 16-bit neon → modern), and the film closes over a pixel
evening-calm sea (夕凪) with the Yunagi.Cloud product line.

Everything is generated by code in this folder: the 5×7 pixel font, every
animation, the copy, the chiptune score and all sound effects. Unifont is used
only for the CJK glyphs.

## Timeline

| Time | Era | Content |
| --- | --- | --- |
| 0–4 s | terminal | "What can AI do?" typed on a black screen |
| 4–14 s | 1-bit paper | 1943 McCulloch & Pitts · 1950 Imitation Game · 1956 Dartmouth · 1958 Perceptron · 1966 ELIZA |
| 14–16 s | winter | 1973 first AI winter (funding meter drains, hotbar freezes) |
| 16–18 s | amber CRT | 1986 backpropagation |
| 18–23 s | green CRT | 1997 Deep Blue · 1998 LeNet · 2009 ImageNet (colour floods in) |
| 23–31 s | 16-bit neon | 2012 AlexNet · 2014 GANs · 2016 AlphaGo / Move 37 · 2017 Transformer |
| 31–41 s | synth | 2020 GPT-3, AlphaFold 2 · 2022 ChatGPT (the drop), diffusion · 2023 frontier race · 2024 reasoning |
| 41–45 s | clean | 2025–26 AI agents |
| 45–48 s | clean | All 15 skills → "What will you build with it?" |
| 48–60 s | dusk | Yunagi.Cloud: Compute, Domains, AI Inference, six-metro network, "Build on Yunagi." |

## Files

| File | Role |
| --- | --- |
| `timeline.py` | Shared timing: eras, transitions, scenes, skills. Video and audio both read it, which keeps them in sync. |
| `pixfont.py` | Hand-drawn proportional 5×7 font and 3×5 HUD font. |
| `gfx.py` | 480×270 canvas, primitives, Bayer-dithered fades and gradients, 4× upscale with pixel grid, scanlines and bloom. |
| `hud.py` | Era palettes and backgrounds, year odometer, timeline ruler, text log, skill hotbar and unlock pop-ups. |
| `scenes.py` | One illustration per milestone. |
| `ending.py` | Intro, the closing question and the Yunagi sequence. |
| `render.py` | Frame compositor, era transitions and encoder. |
| `audio.py` | Synthesiser, score, sound design and mix (limiter, echo, convolution reverb). |
| `worldmap.txt` | 96×32 land mask for the network map, generated with `global-land-mask`. |

## Build

```sh
pip install -r requirements.txt
python3 audio.py score.wav                       # ~10 s
python3 render.py video video_noaudio.mp4        # ~2.5 min on 4 cores
ffmpeg -i video_noaudio.mp4 -i score.wav -c:v copy -c:a aac -b:a 256k \
       -shortest -movflags +faststart what-ai-can-do.mp4
```

For previews: `python3 render.py stills OUT_DIR 12.5 34.0` or
`python3 render.py sheet sheet.png 0 60 24`.

Product facts (prices, 312 TLDs, six metros, 99.9% SLA, 38 s deploy, Lotus
Diffusion-1) come from the Higan Holdings site in `AlexWhiteHK/AutoHandling2027`.
