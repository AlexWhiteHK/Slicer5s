# What AI Can Do — a 60-second dungeon run through AI history

`what-ai-can-do.mp4` — 1920×1080, 30 fps, 60 s, H.264 + AAC stereo.

A pixel-art promo/explainer staged as a dungeon crawler. AI is the hero. Every
year is a floor, every milestone is an encounter, and the hero keeps evolving:

**SPARK → PERCEPTRON → NEURAL KNIGHT → DEEP SEER → TRANSFORMER DRAKE → FOUNDATION TITAN → AGENT**

Each win levels the hero up (LV 1 → 19) and drops a skill into the hotbar
(15 in total). The colour depth of the dungeon follows the era — 1-bit
parchment, an ice cave for the AI winter, amber and green phosphor, 16-bit
neon, synthwave, then a clean final floor — while the bottom-left log keeps
the real history. The run ends on the surface at dusk (夕凪, the evening
calm) with Lotus AI Lab's model lines, served on Yunagi.Cloud.

Everything is generated by code in this folder: the pixel font, sprites,
animation, copy, chiptune score and sound effects. Unifont is used only for
CJK glyphs.

## Files

| File | Role |
| --- | --- |
| `timeline.py` | Shared timing: eras, encounters, wins, evolutions, HP, skills. Video and audio both read it. |
| `pixfont.py` | Hand-drawn proportional 5×7 font, 3×5 HUD font. |
| `gfx.py` | 480×270 canvas, primitives, Bayer-dithered fades and gradients, 4× upscale with pixel grid, scanlines and bloom. |
| `sprites.py` | The hero's seven forms and the monsters, drawn as colour-role grids that each era maps to its own palette. |
| `dungeon.py` | Scrolling dungeon rooms per era, the hero (walk, attack, hurt, frozen, evolving), battle UI helpers. |
| `battles.py` | One encounter per milestone. |
| `assets.py` | Shared pixel assets: the handwritten digit, ImageNet tiles, the GAN painting, the protein chain, the lotus painting. |
| `hud.py` | Era palettes, year odometer, ruler, history log, RPG status panel, skill hotbar and loot pop-ups. |
| `ending.py` | Intro, the closing question and the Lotus AI Lab / Yunagi.Cloud ending. |
| `render.py` | Frame compositor, era transitions and encoder. |
| `audio.py` | Synthesiser, score and battle sound design (hits, bursts, level-ups, evolutions), mix and limiter. |
| `worldmap.txt` | 96×32 land mask for the network map, generated with `global-land-mask`. |

## Build

```sh
pip install -r requirements.txt
python3 audio.py score.wav                       # ~10 s
python3 render.py video video_noaudio.mp4        # ~2.5 min on 4 cores
ffmpeg -i video_noaudio.mp4 -i score.wav -c:v copy -c:a aac -b:a 256k \
       -shortest -movflags +faststart what-ai-can-do.mp4
```

For previews: `python3 render.py stills OUT_DIR 12.5 34.0` or
`python3 render.py sheet sheet.png 0 60 24`.

Lotus AI Lab and Yunagi.Cloud facts (model lines, GLM/Kimi base models,
SWE-bench/DeepSWE, GPU rows in Tokyo and Hong Kong, L40S/H100) come from the
Higan Holdings and Lotus AI Lab pages in `AlexWhiteHK/AutoHandling2027`.
